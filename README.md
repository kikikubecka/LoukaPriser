# 🌾 Louka tisíce příšer

Survivor roguelike — přežij den na louce plné příšer! (🇨🇿/🇬🇧/🇵🇱)

## ▶️ Jak hrát
Otevři `index.html` v prohlížeči (Android/iPhone/PC) s připojením k internetu.
Při prvním spuštění se hra pár sekund překládá (React + překladač se stahují z CDN).

## 🚀 Deploy (Netlify)
Přetáhni složku s `index.html` na https://app.netlify.com/drop — a máš veřejný odkaz.

## 📁 Struktura
- `index.html` — kompletní samostatná hra (jediný soubor, spustitelný v prohlížeči)
- `src/game.tsx` — zdrojový kód hry (React + TypeScript)

## 🎮 Ovládání
- **PC:** WASD/šipky = pohyb · mezerník = úhyb · E = ultimátní schopnost · P = pauza
- **Telefon:** joystick vlevo dole · tlačítka úhyb/ultimátní schopnost

## 🛠 Postaveno na
React 18 · TypeScript · Canvas 2D · Web Audio
